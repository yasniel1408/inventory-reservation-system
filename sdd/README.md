# SDD

Esta carpeta contiene los artefactos de Specification Driven Development del proyecto: define que se quiere construir.

## Contenido

- `user_histories/`: comportamiento esperado en historias Gherkin.
- `specs/`: especificaciones funcionales, dominio, API, criterios y tests.
- `plans.md`: indice de planes.
- `plans/`: planes tecnicos versionados.
- `tasks.md`: indice de tableros.
- `tasks/`: tareas ejecutables derivadas de los planes.

## Relacion con Harness

SDD define el que. El harness define el como trabajan Codex, agentes, skills y memoria.

Por eso `skills/`, `.agents/`, `AGENTS.md`, `HARNESS.md` y `memory/` se mantienen fuera de esta carpeta.
