# Specs del Sistema de Reservas de Inventario

Esta carpeta contiene el paquete inicial de especificación para el challenge.

Orden recomendado:

1. `spec.md`: especificación de producto y comportamiento.
2. `domain-model.md`: entidades, estados e invariantes.
3. `api-spec.md`: contrato REST previsto antes de generar OpenAPI formal.
4. `acceptance-criteria.md`: checks observables de aceptación.
5. `test-spec.md`: verificación requerida backend y frontend.

Estos archivos existen antes de implementación para preservar el workflow Architecture First requerido por el challenge.
