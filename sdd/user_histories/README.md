# Historias de Usuario

Historias de usuario del challenge "Inventory Reservation System", escritas en Gherkin en español.

Convenciones:

- Cada archivo `.feature` representa una capacidad funcional o transversal.
- Los escenarios cubren comportamiento observable, errores y condiciones de carrera relevantes.
- La carpeta mantiene el nombre `user_histories` por convención de repo.
- Las historias deben guiar los artefactos SDD posteriores: `spec.md`, `sdd/plans.md`/`sdd/plans/`, `sdd/tasks.md`/`sdd/tasks/` y contrato OpenAPI.
