# Plans

Los planes definen como se va a construir una capacidad.

## Convenciones

- Usar formato `<id>-<nombre>.md`.
- Mantener `plans.md` como indice raiz.
- Un plan debe elegir tecnologias, arquitectura, estrategia de datos, validaciones y riesgos.
- Un plan no debe ser una lista larga de tareas; para eso existe `tasks/`.

## Planes

- `001-inventory-reservation-system.md`: challenge de reservas de inventario.
