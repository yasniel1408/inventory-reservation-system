# CLAUDE.md

Este archivo existe para que Claude Code use el mismo harness que Codex, OpenCode u otras herramientas.

La fuente canonica del proyecto es:

@AGENTS.md

Tambien debe respetarse el selector de skills:

@skills/SELECTING_SKILLS.md

## Regla de Uso

- No duplicar reglas aca salvo que sean especificas de Claude Code.
- Antes de ejecutar cualquier tarea del repo, leer `skills/` como indica `AGENTS.md`.
- Para desarrollo, seguir el flujo de `skills/development-flow/SKILL.md`.
- Si hay conflicto entre este archivo y `AGENTS.md`, gana `AGENTS.md`.
