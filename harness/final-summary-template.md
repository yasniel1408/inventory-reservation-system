# Template: Resumen Final

Usar este template al cerrar un flujo o una tarea relevante.

```md
## Resumen Final

- Trabajo realizado:
- Archivos cambiados:
- Agentes usados:
- Skills aplicadas:
- Modelos/perfiles usados:
- Fallback de modelo:
- Camino tomado:
- Validaciones ejecutadas:
- Resultado de validaciones:
- Riesgos restantes:
- Pendientes:
- Handoff final:
```

## Reglas

- No declarar completo algo que no fue validado.
- Si una validacion no se pudo ejecutar, explicar por que.
- Si queda riesgo, nombrarlo de forma concreta.
- Si hubo aprendizaje reusable, indicar si paso a `skills-expert`.
