# Template: Status

Usar este template para reportes recurrentes durante ejecucion.

```md
## Status

- Etapa:
- Agente activo:
- Modelo/perfil:
- Skills seleccionadas:
- Tarea actual:
- Risk level:
- Archivos owner:
- Bloqueo:
- Decision relevante:
- Validacion en curso:
- Siguiente paso:
```

## Reglas

- Mantenerlo corto.
- Reportar cuando cambia etapa, agente activo, bloqueo, risk level o siguiente paso.
- Si el flujo puede pausarse, actualizar `memory/progress.md`.
- Si cambia la tarea tecnica, actualizar `memory/current-task.md`.
