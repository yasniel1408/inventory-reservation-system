# Template: Brief de Sub-agente

Usar este template cuando `team-leader` instancia o deriva trabajo a `developer`, `reviewer`, `tester`, `delivery-manager` o `skills-expert`.

```md
## Brief de Sub-agente

- Para:
- Objetivo:
- Risk level:
- Modelo/perfil recomendado:
- Condiciones de escalamiento de modelo:
- Archivos owner:
- Skills requeridas:
- Fuentes ya revisadas:
- Resumen masticado:
- Decisiones ya tomadas:
- Fuentes a abrir solo si hay duda o si se edita/valida:
- Restricciones:
- Validacion esperada:
- Puede paralelizarse:
- No tocar:
- Handoff esperado:
```

## Reglas

- El brief debe ser autosuficiente, pero no debe copiar todo el contexto del `team-leader`.
- El brief debe indicar exactamente que fuentes fueron revisadas y que conclusiones importan.
- El sub-agente no debe cargar todo desde cero; abre solo lo necesario.
- Si el brief no alcanza, el sub-agente escala al `team-leader`.
- Si el riesgo sube, el sub-agente escala modelo/perfil antes de continuar.
